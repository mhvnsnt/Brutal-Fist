## Existing architecture to preserve

- Bannon is the authoritative fighter/content source.
- **NO GLB = NO CHARACTER.**
- Every discovered Bannon GLB must be inventoried and mapped; attire count is unbounded.
- GLB validation requires rig/skin/rest-pose/animation/transform gates; UNKNOWN never passes.
- Schwarzerblitz remains native runtime authority.
- Grok v7 architecture is an additive source behind BF contracts.
- Default match rules are KO-only.
- Pins, submissions, wrestling rules, configurable rounds, and time limits including infinity belong in Match Options and are not enabled by default.
- No fighter-specific bone orientation hacks.
- Current P1/P2 presentation uses a shared opposing match-facing basis with root presentation rotation.

## Current integration target

Consolidate the strongest verified systems from Grok v1-v7, Bannon, Schwarzerblitz, NightSky, and Combat-RPG behind one Brutal Fist runtime rather than creating competing engines.
