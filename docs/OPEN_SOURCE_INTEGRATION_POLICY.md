# Open-source integration policy

Use open-source components to accelerate infrastructure, conversion and runtime work only when their licenses and technical compatibility are verified.

Preferred strategy:
1. integrate permissively licensed engine/tooling components;
2. preserve upstream license and attribution files;
3. isolate third-party code at clear boundaries;
4. keep Bannon assets and Brutal Fist assets separate from third-party game assets;
5. replace upstream game content rather than assuming that public availability grants reuse rights;
6. record the exact source commit and license for every vendored component.

Important: modifying a copyrighted work does not automatically make the resulting work legally unrestricted. Public/open-source availability and copyright permission are separate questions.

For Schwarzerblitz, use the engine source according to its published license and replace separately restricted game content with Bannon/Brutal Fist content.
